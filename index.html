01 / THE FILM

Every frame is a function of time.

The launch showreel isn't edited — it's computed. scene.html exposes render(t): HUD, pixel wipes, kinetic type, 3D browser/phone compositions, rings, cursor trail, reticle. No CSS animations, no wall-clock — headless Chrome draws each frame, ffmpeg stitches it, Python synthesizes the score. Scrub it with the chapters.

02 / THE CRAFT

Motion is
the résumé.

Five techniques from the film, running live in your browser right now. Scroll to travel through them.

01 — FRAME-EXACT RENDER

render(t), not play().

Every visual is a pure function of the timestamp. Scrub to any second and you get the identical pixels — that's what makes headless rendering deterministic.

02 — LIVE FOOTAGE, SCRIPTED

Clicks performed by robots.

Site footage is recorded frame-by-frame with scripted scroll, clicks and typing, then swapped in per-frame. The theme click in the film is a real event.

03 — SYNTHESIZED SCORE

120 BPM, −14 LUFS, zero samples.

scripts/sound.py synthesizes music + SFX on scene event times with numpy/scipy. No stock audio, nothing licensed.

04 — PIXEL WIPES & RETICLE

Transitions with a grid.

Scene changes wipe through a pixel lattice while the focus reticle tracks the subject — the same cursor FX that ships in the template itself.

05 — POSTER AS A PROGRAM

thumb.html → PNG. cover.html → PNG.

The LinkedIn thumbnail (4:5) and repo cover (16:9) are static layouts rendered to PNG by the same pipeline — one command builds everything.

npm run build → video · sound · mux · linkedin · thumbnail · cover
